# 황서린 코치의 퍼스널 트레이닝 랩

황서린 코치의 PT 수업·인스타 콘텐츠 제작을 돕는 **단일 파일 웹앱**입니다.
링크 하나만 공유하면 되고, 코치가 직접 쓰거나 관리자가 대신 써줄 수 있습니다.

## 지금 들어있는 기능

**1차 · 핵심**
- **고객 관리** — 고객을 한 번 등록하면 다른 모든 탭에서 불러 씁니다. (데이터는 브라우저에 저장)
- **운동 프로그램 생성기** — 목표·수준·기구·주 횟수·기간을 넣으면 주차별(세트/반복/점진 부하) 프로그램을 자동 생성. 8주 이상은 4주마다 디로드 자동. PDF 저장·텍스트 복사(전송용) 지원.
- **인스타 콘텐츠 생성기** — 주제 하나로 릴스 훅·대본·캡션·해시태그를 황서린 코치 말투로 생성.

**2차 · 확장**
- **주간 체크인 메시지** — 고객 상황(순조·정체기·저조·복귀·동기부여)에 맞춘 메시지 초안 생성.
- **30일 콘텐츠 캘린더** — 8가지 유형을 섞어 한 달치 포스팅 아이디어 자동 편성. 아이디어 → 인스타 생성기 바로 연동.
- **FAQ 챗봇** — 폼·식단·통증 등 자주 묻는 질문에 코치 말투로 자동 응답(규칙 기반). 추후 GPT/Gemini 연동 가능.

브랜드 색(오렌지/라임)과 이름은 `index.html` 상단 `:root` 변수와 `COACH`·`BRAND_NAME` 값으로 언제든 교체할 수 있습니다.

**고객 포털 (읽기 전용)**
- 고객이 **개인 링크로 자기 프로그램·진행 기록을 확인**할 수 있어요. (코치 작성 → 고객 열람)
- 켜려면 무료 **Firebase**를 한 번 연결하면 됩니다. `firebase-config.js` 한 파일만 채우면 코치 앱과 포털에 동시 적용. 설정 안 하면 기존처럼 이 브라우저에만 저장돼요(포털 꺼짐).
- 고객 관리 화면의 **📋 기록**으로 진행 메모를 남기고, **🔗 포털 링크**로 고객에게 링크를 보냅니다.

## 함께 제공되는 파일
- `index.html` — 코치용 앱 본체
- `portal.html` — 고객 포털(읽기 전용). `portal.html?demo=1` 로 미리보기 가능
- `firebase-config.js` — Firebase 설정(고객 포털용). 비우면 포털 꺼짐
- `Firebase-설정-가이드.html` — 고객 포털 켜는 법(단계별)
- `사용법-가이드.html` — 코치용 사용법
- `roadmap.png` — 전체 기능 로드맵 이미지

> 배포: 위 파일들을 GitHub에 함께 올리고 Vercel에 연결하면 됩니다. (`firebase-config.js`·`portal.html`도 같은 폴더에 두세요.)

## 앞으로 붙일 고급 모듈 (예정)
영상 자세 분석(포즈 추정) · 브랜드 코칭 챗봇(GPT/Gemini) · 릴스 자동 제작 파이프라인.

## 데이터 저장 방식

고객·프로그램 정보는 **사용하는 브라우저(localStorage)** 에만 저장됩니다. 서버로 전송되지 않습니다.
- 장점: 별도 서버·비용·API 키가 필요 없고, 개인정보가 외부로 나가지 않음.
- 유의: 브라우저를 지우거나 다른 기기로 바꾸면 데이터가 함께 사라집니다. 여러 기기에서 같은 데이터를 공유하려면 다음 단계에서 Firebase 같은 가벼운 DB를 붙이면 됩니다.

## 배포 방법 (GitHub → Vercel 자동 배포)

1. GitHub에서 새 저장소를 만들고 `index.html` 을 업로드합니다. (README는 선택)
2. [vercel.com](https://vercel.com) 로그인 → **Add New → Project** → 방금 만든 저장소 선택.
3. 프레임워크는 **Other(정적 사이트)** 그대로 두고 **Deploy** 클릭.
4. 몇 초 뒤 `https://프로젝트이름.vercel.app` 링크가 나옵니다. 이 링크를 코치에게 공유하면 끝.
5. 이후 `index.html` 을 수정해 GitHub에 올릴 때마다 Vercel이 자동으로 다시 배포합니다.

> 더 간단히 테스트만 하려면 `index.html` 파일을 그냥 더블클릭해 브라우저로 열어도 됩니다.

## 꼭 지키는 안전 원칙

- 건강·부상·식단 관련 출력에는 "의료 조언 아님, 전문의 상담 권장" 문구를 표시합니다.
- 고객 개인정보는 최소한만, 브라우저 로컬에만 저장합니다.
- 목소리 복제 등은 본인 서면 동의가 있을 때만 진행합니다.
